# NOVARA — Full front-end concept

Distinct brand and interface, separate from Palatial. Built with Next.js, React, TypeScript and Lucide.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Backend work needed for production
- Authentication and profiles
- Database-backed posts, follows, circles, tasks and chat history
- Real-time messaging, voice/video calls (WebSockets + WebRTC/SFU/TURN)
- Video uploads, transcoding, adaptive streaming, CDN and moderation
- AI model gateway and usage limits
- Creator analytics, advertising, subscriptions and payouts
- Security, privacy, abuse prevention, accessibility and deployment/monitoring
